# Enchant Reroll

Enchant Reroll is a Minecraft mod focused on flexible enchantment rerolling, progression, and player-driven item customization. This repository is the official issue tracker for bug reports, feature ideas, balance feedback, and compatibility problems.

## Reporting a bug or issue

We want to fix problems quickly, so please use the issue tracker and include as much relevant detail as possible.

Before opening a new issue:
- Search existing issues to avoid duplicates
- Verify the problem still happens in the current version
- Try to reproduce it with a minimal setup when possible

Please include:
- Minecraft version
- Mod version
- Loader (Forge, Fabric, NeoForge, etc.)
- A clear description of the problem
- Steps to reproduce
- Expected behavior
- Actual behavior
- Screenshots, videos, or crash logs if available

## Issue templates

Use the built-in issue forms in the GitHub Issues tab for a faster and more complete report.

## Project goals

This project aims to provide a smooth, fair, and configurable enchantment reroll experience while staying compatible with modern Minecraft modding ecosystems.
