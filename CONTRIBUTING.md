# Contributing to Enchant Reroll

Thank you for helping improve the Enchant Reroll mod! This guide will help you report bugs and issues effectively.

## How to Report a Bug or Issue

### Before You Report
- **Check existing issues** — Use the [Issues page](https://github.com/MaybeLight/enchant-reroll/issues) to search for similar reports. Your issue might already be reported or fixed.
- **Verify the problem** — Try to reproduce the issue consistently to confirm it's not a one-time occurrence.
- **Gather details** — Note when it happens, what you were doing, and any error messages.

### Creating an Issue

1. Go to the [Issues tab](https://github.com/MaybeLight/enchant-reroll/issues) and click **New Issue**
2. Use a clear, descriptive title (e.g., "Reroll button crashes when inventory is full")
3. Fill out the following details:

#### Required Information

**Minecraft Version:**
- Which Minecraft version are you running? (e.g., 1.20.1)

**Mod Version:**
- Which version of Enchant Reroll are you using? (e.g., 1.0.0)

**Mod Loader:**
- Are you using Forge, Fabric, NeoForge, or another loader?

**Description:**
- What went wrong? Be specific and concise.
- What were you trying to do when the bug occurred?

**Steps to Reproduce:**
1. First step
2. Second step
3. Continue until the issue occurs...

**Expected Behavior:**
- What should have happened?

**Actual Behavior:**
- What actually happened instead?

#### Optional but Helpful

- **Screenshots/Video** — Attach images or a short clip showing the bug
- **Error Log** — If there's a crash, paste the relevant section from your logs (usually in `.minecraft/logs/latest.log`)
- **Mods List** — List other mods you have installed (the bug might be a compatibility issue)
- **Notes** — Any additional context that might help diagnose the issue

### Example Issue Report

```
**Title:** Enchanted item disappears after reroll

**Minecraft Version:** 1.20.1

**Mod Version:** 1.0.2

**Mod Loader:** Fabric

**Description:**
When I reroll an enchantment on a diamond pickaxe, the pickaxe sometimes disappears from my inventory.

**Steps to Reproduce:**
1. Place a diamond pickaxe in the reroll station
2. Apply a reroll
3. Click to retrieve the item
4. Item does not appear in inventory

**Expected Behavior:**
The rerolled pickaxe should appear in my inventory

**Actual Behavior:**
The pickaxe is gone; it's not on the ground or in the station either.
```

## Bug Report Tips

✓ **Do this:**
- Be respectful and patient
- Provide as much detail as possible
- Follow the format above
- Test with other mod configurations if possible

✗ **Don't do this:**
- Spam or duplicate report the same issue multiple times
- Report vague issues without context ("it doesn't work")
- Assume something is a bug without testing thoroughly

## Other Ways to Help

- **Suggest features** — Open an issue with the label `enhancement`
- **Ask questions** — Use Discussions (if enabled) for setup help
- **Share fixes** — Submit pull requests with improvements
